# AccessAI — Devpost draft

## Problem Statement

Students frequently encounter information that is technically available but practically
inaccessible: complicated explanations, long articles, jargon, overwhelming material, and
uncertainty about what to do next. Generic chatbots answer without knowing the learner's
goal, level, style, or progress.

## Solution Overview

AccessAI is an adaptive AI accessibility layer: paste complex content → get personalized
explanations, terms, examples, action steps, and quizzes; turn goals into milestone plans;
track progress; and receive recommendations that explain WHY. Accessibility controls are
core to the product, not an afterthought.

## Key Features

- Understand: adaptive explanation + key ideas + terms + example + steps + quiz + "explain again" variants
- Study planner: goal → milestones → tasks with estimates and progress tree
- Adaptive insights with explainable recommendations
- Accessibility mode (larger text, readability, focus mode, reduced motion, keyboard support)
- Progress dashboards (Recharts), history, knowledge memory, honest demo fallback

## Technologies Used

React, TypeScript, Vite, Tailwind CSS v4, Recharts, Lucide, FastAPI, Pydantic,
OpenAI-compatible LLM API, PostgreSQL (schema provided).

## Target Users

Students facing dense material, self-learners entering technical fields, and learners who
need different explanation styles or clearer next steps. Empowerment-focused; complements teachers.
